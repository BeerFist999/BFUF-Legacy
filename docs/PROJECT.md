# BFUF-Legacy

## О проекте

**BFUF-Legacy** — лёгкий аддон интерфейса для World of Warcraft, развиваемый как совместимый с классическими версиями игры и опирающийся только на штатный API Blizzard. Проект нацелен на сохранение предсказуемого, расширяемого и независимого от сторонних библиотек кода.

## Цели

- Предоставить базу для отображения и настройки unit frames.
- Сохранить совместимость с поддерживаемыми legacy-версиями World of Warcraft.
- Минимизировать внешние зависимости и нагрузку на клиент.
- Обеспечить понятную модульную структуру для дальнейшего развития.
- Документировать решения и изменения проекта.

## Архитектура

Проект строится по модульному принципу. Каждый модуль отвечает за одну предметную область: инициализацию, работу с фреймами, конфигурацию, события или визуальные элементы. Модули взаимодействуют через явные интерфейсы и используют API Blizzard напрямую.

Основные слои:

- ядро: загрузка аддона, регистрация модулей и обработка событий;
- представление: создание и обновление unit frames;
- конфигурация: хранение и применение пользовательских настроек;
- интеграция: обращения к API Blizzard и адаптация различий клиентов.

## Используемые технологии

- Lua;
- XML при необходимости декларативного описания интерфейса;
- Blizzard World of Warcraft API;
- файлы TOC для описания аддона и порядка загрузки.

## Поддерживаемые версии World of Warcraft

Целевые версии уточняются по мере разработки. Проект ориентирован на legacy-клиенты World of Warcraft; конкретный список версий и ограничения совместимости будет поддерживаться в этом разделе.

## Принципы разработки

- Использовать только Blizzard API.
- Не добавлять зависимость от Ace3.
- Сохранять модули небольшими и изолированными.
- Делать изменения совместимыми с существующей архитектурой.
- Сопровождать значимые решения документацией.
- Проверять код в поддерживаемых клиентах игры.
