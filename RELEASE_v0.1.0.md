# BFUF v0.1.0 — Stable Foundation

First stable release of BFUF.

## Highlights

- Stable Player and Target Frames
- Secure Target interaction and click handling
- Event-driven unit lifecycle management
- Health reaction colors
- Stable square 2D portraits
- Foundation for future unit frame development

## Known limitations

- Portraits use Blizzard 2D portrait textures.
- 3D portraits are not included in this release.
